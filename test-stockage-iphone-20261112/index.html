PEP — Test du stockage sur iPhone

Ce diagnostic vérifie si Chrome ou Safari conserve une donnée entre deux ouvertures. Il ne demande aucun identifiant ni jeton SSO.

Vérification…

Comment tester
  1. Ouvrez cette page dans Chrome, en navigation normale.
  2. À la première ouverture, la page enregistre un témoin de test.
  3. Fermez l’onglet et Chrome, puis rouvrez exactement la même adresse dans Chrome.
  4. Relevez le message affiché en haut de la page.

Ce test utilise uniquement le stockage local du site pep.147ruedebercy.fr ; aucune donnée personnelle n’est enregistrée ni envoyée.
