PEP — Essai de connexion persistante sur iPhone

État de la connexion sur cet appareil

Vérification en cours…

Seul le portail SSO V2 peut confirmer qu'un jeton est encore valable. Cette page vérifie uniquement sa présence locale.

Portail SSO de test

Avant le premier essai, indiquez l’adresse /dev obtenue dans Apps Script, via « Déployer → Tester les déploiements ». Elle doit correspondre à la version d’essai du portail.

Déroulement de l'essai

  1. Ouvrez le portail de test et identifiez-vous une fois avec votre code habituel.
  2. Dans le portail de test, cliquez sur « Terminer la connexion sur cet appareil ».
  3. Vous reviendrez sur cette page : un jeton doit alors être indiqué comme mémorisé.
  4. Fermez complètement Chrome, rouvrez cette même adresse et vérifiez que le jeton est toujours mémorisé.
  5. Cliquez sur « Ouvrir le portail SSO de test » : le portail doit reconnaître la session sans nouveau code.

Cette opération efface la copie conservée sur cet appareil, mais ne révoque pas la session sur le serveur. Pour révoquer une session, utilisez aussi « Se déconnecter » dans le portail SSO.
