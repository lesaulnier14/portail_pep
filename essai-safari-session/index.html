Tester la reconnexion

Ce test est séparé de la page d'accueil habituelle de la résidence. Il utilise le jeton mémorisé sur ce navigateur et le transmet au serveur SSO par HTTPS POST, jamais dans l'URL.

Première utilisation dans Safari

  1. Si aucun jeton n'est présent, appuyez sur « Ouvrir le portail SSO » puis identifiez-vous avec votre code habituel.
  2. Sur la liste des applications, appuyez sur « Conserver ma connexion sur PEP (transfert sécurisé) ».
  3. Vérifiez le message « Jeton SSO conservé sur PEP » et revenez ici dans Safari.
  4. Fermez complètement Safari, ouvrez à nouveau cette page et appuyez sur « Ouvrir le portail SSO ».

Faites le test hors navigation privée, toujours dans Safari. Votre session Chrome reste indépendante et inchangée.
